# ⚡ Omarchy VLESS Proxy & DNS Switcher

Универсальный локальный клиент VLESS Reality / XHTTP / VMess / Trojan / Xray и виджет для панели **Omarchy** (Arch Linux / Hyprland). Поддерживает любые ссылки подписок (BeregVPN, Luchshiy VPN, Weaselmirror, Remnawave с HWID), позволяет на лету переключать серверы и умные DNS-профили (Comss, GeoHide, Cloudflare, AdGuard) в один клик.

## 🔄 Управление подписками на лету

Вы можете сменить или обновить ссылку на подписку в любой момент без переустановки:

- **Через графический интерфейс**:
  - Нажмите **ПКМ** по значку молнии на панели Omarchy.
  - В поле **«URL подписки»** вставьте новую ссылку и нажмите **«ОК»**.
- **Через консоль**:
  ```bash
  # Импортировать новую ссылку
  ~/Projects/omarchy-vless-proxy/core/proxy.sh sub "https://новая_ссылка"

  # Обновить текущую сохраненную подписку
  ~/Projects/omarchy-vless-proxy/core/proxy.sh sub
  ```

## 🎮 Управление через панель Omarchy

После установки на панели появляется значок молнии (**⚡**):

- **ЛКМ (Левый клик)**:
  - **Включение / Выключение прокси**.
  - Значок подсвечивается **зеленым**, когда прокси активен, и серым, когда выключен.
  - При выключении система и браузеры мгновенно переходят на прямое соединение (интернет не зависает).
- **ПКМ (Правый клик)**:
  - Открывает графическое меню настроек (**Zenity / Tkinter**).
  - Позволяет выбрать сервер выхода, DNS-профиль и обновить ссылку на подписку.
- **Наведение мыши (Hover)**:
  - Отображает всплывающую подсказку с текущим сервером, DNS-провайдером и статусом.

## 🧠 Интеграция с AI инструментами и приложениями

Проект включает готовые смарт-обёртки в `~/.local/bin/`, которые автоматически направляют трафик через прокси, когда он запущен, и возвращаются на прямое соединение, когда прокси выключен:

1. **Chromium в Hyprland**:
   - По умолчанию Chromium в Wayland/Hyprland игнорирует настройки системного прокси GNOME GSettings. Обёртка запускает Chromium с эмуляцией окружения GNOME, восстанавливая бесшовное переключение прокси в реальном времени.
2. **T3 Code (CLI `t3` и GUI `t3code`)**:
   - Автоматически проверяет порт `127.0.0.1:10809` при старте. Если прокси работает, активирует HTTP/HTTPS/SOCKS прокси для агентных запросов.
3. **Google Antigravity (`agy` CLI и `antigravity-ide`)**:
   - Для работы Google AI / Gemini API из РФ трафик направляется через европейские ноды (Швеция / Финляндия). Конфигурация `Antigravity IDE` автоматически дополняется параметром `"http.proxy": "http://127.0.0.1:10809"`.

## 🌐 Поддерживаемые DNS-профили

В меню настроек (ПКМ) доступны 5 профилей DNS:

1. **Системный / Серверный (по умолчанию)**:
   - Резолв осуществляется напрямую через исходящий VLESS-сервер. Максимальная скорость и минимальная задержка.
2. **Comss.one Smart DNS**:
   - DoH-профиль (`https://dns.comss.one/dns-query`) с bootstrap IP `185.146.157.78`. Отлично подходит для доступа к зарубежным сервисам (ChatGPT, Claude, Discord, Spotify).
3. **GeoHide Smart DNS**:
   - `193.233.112.88` со специализированной прямой маршрутизацией.
4. **Cloudflare DoH**:
   - Зашифрованный DNS over HTTPS (`https://1.1.1.1/dns-query`).
5. **AdGuard DoH**:
   - Зашифрованный DNS over HTTPS (`https://dns.adguard-dns.com/dns-query`) с фильтрацией рекламы и трекеров.

## 🇷🇺 Раздельное туннелирование для сервисов РФ (Direct Bypass)

Все российские сервисы и государственные порталы работают **напрямую без прокси**, что предотвращает блокировки со стороны анти-DDoS фильтров и капчи:

1. **Маршрутизация Xray Core (GeoIP / GeoSite)**:
   - Включает базы `geoip:ru` и `geosite:category-ru` (Loyalsoldier).
   - Все зоны `.ru`, `.su`, `.рф`, мессенджер **MAX** (`max.ru`), **Госуслуги** (`gosuslugi.ru`, `esia.gosuslugi.ru`), сервисы **Яндекса** (`yandex.ru`, `ya.ru`), **VK** (`vk.com`), **Mail.ru**, **Авито**, **Ozon**, **Wildberries**, **Кинопоиск**, банки (**Сбер**, **Т-Банк**, **ВТБ**, **Альфа**), платежные шлюзы (НСПК, СБП, Мир) и все IP-диапазоны провайдеров РФ направляются через исходящий поток `direct` (напрямую через ваше интернет-соединение).
2. **Системный и браузерный байпас (`NO_PROXY` / GSettings `ignore-hosts`)**:
   - Chromium и LibreWolf автоматически получают список исключений, поэтому обращаются к российским сервисам напрямую минуя локальный прокси.

## 💻 Полезные консольные команды

Все команды доступны из любого терминала:

```bash
# Переключить состояние прокси (вкл / выкл)
zapret-toggle

# Открыть графическое окно выбора сервера, DNS и ввода подписки
zapret-settings

# Вывести статус в формате JSON (используется виджетом панели)
zapret-status

# Протестировать внешний IP через SOCKS5 и HTTP
~/Projects/omarchy-vless-proxy/core/proxy.sh test

# Посмотреть список всех доступных серверов
~/Projects/omarchy-vless-proxy/core/proxy.sh list

# Запустить конкретный сервер вручную через CLI
~/Projects/omarchy-vless-proxy/core/proxy.sh start sweden
```

## ⚠️ Важные замечания и сосуществование с VPN

- **Сосуществование с AmneziaVPN**:
  - Если на компьютере параллельно включен AmneziaVPN (интерфейс `amn0`), его MTU составляет 1280. Пакеты VLESS Reality ClientHello (размером ~1573 байта) могут фрагментироваться и блокироваться. Для стабильной работы VLESS Reality рекомендуется отключать AmneziaVPN на время работы прокси.
- **Совместимость с Google AI (`agy` / Antigravity)**:
  - Некоторые серверы VPN (в т.ч. отдельные IP Германии, Эстонии, США) геоблокируются со стороны Google API (`User location is not supported`). Для работы с Google AI используйте серверы **Швеция** или **Финляндия**.
